## قابلیت اتکای GitHub Activity

هر ۱۴ درخواست زندهٔ مشاهده‌شده در Lighthouse و مرورگر پاسخ ۲۰۰ دادند. در چهار مشاهدهٔ مرورگر، envelope دارای تقویم معتبر و ۵۳ هفته بود و خود تقویم رندر شد. هر چهار پاسخ دارای `Cache-Control: public, max-age=0, must-revalidate` و `X-Vercel-Cache: MISS` بودند. در handler یا routeRules TTL یا cache مشترک صریحی برای endpoint تعریف نشده است. این نمونه هیچ cache hit یا محدودیت نرخ Production ثبت نکرد.

در Nitro محلی که هیچ‌یک از نام‌های متغیر token تنظیم نبود، یک درخواست پاسخ 403 با نشانهٔ محدودیت نرخ داد. در دو اجرای جدا، 403 فقط در مرورگر شبیه‌سازی شد و پیام خطای محلی‌شده در هر دو زبان دیده شد. این دو اجرا به‌عنوان رخداد Production شمرده نشدند. هیچ مقدار token خوانده یا در شواهد ثبت نشد.

ویجت پس از mount یک درخواست هم‌دامنه می‌فرستد. handler توکن خصوصی `runtimeConfig.githubToken` را با fallback قدیمی `NUXT_PUBLIC_GITHUB_TOKEN` بررسی می‌کند و پاسخ GraphQL را برمی‌گرداند. کلاینت وجود تقویم را می‌سنجد و در خطا حالت جایگزین دارد. نبود اعتبارسنجی نوع و قالب نام کاربری، بررسی کامل `errors`، timeout صریح و cache کنترل‌شده ریسک عملیاتی‌اند. در این پنجره ویجت قابل قبول بود. اقدام محدود بعدی، اعتبارسنجی ورودی و envelope، تبدیل variables به object و ثبت کد خطای خلاصه‌شده است. حذف fallback یا تغییر cache باید جداگانه بررسی شود.

- **Production PASS.** دو نوبت smoke شش‌موردی، canonical هشت مسیر، hreflang دوسویه برای خانه/فهرست/مقاله، robots و sitemap زنده با ۱۹ URL، noindex رزومه، تعامل منو و زبان، موبایل، دو پوسته، دیالوگ تماس، جزئیات پروژه و جست‌وجو و برچسب وبلاگ بررسی شدند. در ۱۶ حالت مرورگر خطای console یا درخواست analytics ثبت نشد. ارسال پیام بیرونی جزو آزمون نبود.
- **Production RETEST PASS.** در اجرای اولیه، Puppeteer برای دو پاسخ دانلود ۲۰۰ یک buffer خالی برگرداند و همان دو assertion شکست خوردند. بازآزمایی با فایل کامل‌شدهٔ دانلود Chrome و GET مستقل هر دو PDF این محدودیت روش را رفع کرد. بارگیری اصلی Lighthouse هم در سری اولیه شکست خورد، با پروب مستقیم رفع شد و ۲۰ اجرای معتبر مستقل ثبت شد.
- **UNAVAILABLE.** A/B استقرار پیشین، لاگ build اختصاصی Vercel و لاگ runtime خصوصی در دسترس نبودند. دادهٔ میدانی و سنجش بلندمدت نرخ GitHub انجام نشدند.

## اولویت پیگیری

1. پس از بازبینی، ST-04 را ببندید و این پنجره را به‌عنوان مبنای Production برای ST-05 حفظ کنید.
2. تا زمان تغییر بعدی آیکون یا Nitro، تأخیر دو کنترل دیالوگ و semantics کش RSS را جداگانه پیگیری کنید. برای کشف منشأ دقیق قطع اتصال Vercel، زمان، route و مقصد رخداد بعدی را در لاگ دسترس‌پذیر ثبت کنید.
3. برای کار بعدی روی GitHub Activity، اول اعتبارسنجی envelope و پاسخ خطای پایدار را بررسی کنید. split فایل JS نیز ابتدا به انتساب هزینهٔ اجرا به chunk و مسیر نیاز دارد.

## بازتولید و محل شواهد

۱. با Chrome `157.0.8103.79` و Lighthouse `13.6.0`، هر مسیر را پنج بار با فرایند تازه اجرا کنید. ترتیب در `runs[].order` است. `$target` یکی از چهار URL Production است. `$prefix` زیر پوشهٔ موقت قرار می‌گیرد.

```powershell
$env:CHROME_PATH = '<path to Chrome 157.0.8103.79>'
$target = 'https://aliarghyani.ir/blog'
$prefix = '<temporary directory>/blog-en-r1'
node '<Lighthouse 13.6.0>/cli/index.js' $target --only-categories=performance --form-factor=mobile --throttling-method=simulate --locale=en-US --output=json --output=html --output-path=$prefix '--chrome-flags=--headless=new --disable-extensions --lang=en-US --no-proxy-server' --save-assets
```

۲. در JSON از `runs[].route` گروه بسازید و برای هر متریک، میانه و حداقل و حداکثر را از پنج نتیجه محاسبه کنید. ستون‌های منابع در `measurement.requestColumns` هستند. فایل `st03-lighthouse-runs.json` فقط کنترل تاریخی است.

۳. برای QA محلی `pnpm typecheck` و `pnpm build` را اجرا کنید. `node .output/server/index.mjs` را روی `127.0.0.1:3100` اجرا کنید و همان origin را به سه اسکریپت QA محلی بدهید. برای آزمون زنده از context تازه، `Network.setCacheDisabled`، ثبت SSR و `CSS.getPlatformFontsForNode` استفاده کنید. وضعیت دانلود را از فایل نهایی Chrome و PDF خوانده‌شده تعیین کنید.

۴. گزارش‌های کامل، traceها، logها، PDFهای موقت و تصویرها خارج از Git در `%TEMP%/nuxt-portfolio-st04c-evidence` هستند. اسم گزارش هر اجرا در JSON موجود است. SHA-256 فهرست خام `sha256.json` برابر `42b36e75fb6c2383ceff7dbb78f9d89666733a4f03b0e26ddcfa21e680c20427` است.
